# Enpoi Council

[English](README.md) | 中文

此 Web 配置档插件提供用于架构辩论的 `roundtable`、用于头脑风暴的 `chorus`，以及在 `enpoi-orchestration.councils` 中定义的其他议事组。工具返回供参考的综合报告或创意汇总。

## 席位生命周期

席位失败或超时后，议事组会等待 subagent 服务释放该席位，再尝试启动接替者。裁决、证据搜集和总结各自在本阶段结束后释放其子会话的运行资源。议事运行无论成功、失败还是被取消，都会等待剩余子会话停止运行并释放并发名额。释放不会删除会话历史。释放失败会记入议事诊断日志，不会覆盖运行结果或原有错误。

## 模型体验

### 讨论与工具结果

#### 模型看到的内容

各席位接收各自的提示词，并通过裁决者维护的议题记录共享发现。调用方模型只接收最终的工具结果，不接收子会话的轮次。

#### Token 影响

席位发言、裁决、证据搜集和总结分别发起模型调用。最终报告作为工具结果进入调用方的上下文。

#### KV Cache 影响

子会话各自维护请求历史，不与调用方会话共享 KV Cache。接替的席位从新的请求历史开始。

## 已知限制与延后工作

- 议事组与其他子会话共用父 agent（智能体）的 `maxActiveSubagents` 上限。已有运行占用名额时，响应席位数仍可能达不到议事所需的最低比例。

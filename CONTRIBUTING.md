# Contributing

English | [中文](CONTRIBUTING.zh.md)

Thank you for your interest in contributing to Enpoi Harness!

We deeply believe in the power of open source communities, and that belief has shaped this project from the very beginning.

Enpoi Harness is under active development. However, contributing code to this repository is far from the only way to help. There are many other ways to get involved:

- Identify and report issues or bugs on GitHub:
  - Upvote discussions and report reproducible issues that you would like to bring to the team's attention.
- Contribute to the ecosystem:
  - Create a plugin that excites you and share it with others:
    - Associate your GitHub project with the `dsh-plugin` topic to help others discover your plugin.
  - Write blog posts and how-to guides about Enpoi Harness.
  - Answer questions and help other members of the community.

Enpoi Harness is designed to be deeply customizable. We do not believe that packages in the official repository are inherently more important than packages created by the community. You may consider this repository an idea, an official showcase, and a source of inspiration, but not a mandate from us.

We have already seen exciting projects emerge from the community, and we hope to see the ecosystem continue to grow in its own directions.

Into the unknown.

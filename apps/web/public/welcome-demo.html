Step 1 · Welcome

Welcome to Enpoi Harness

A local AI workspace. It runs on this machine, talks only to the providers you choose, and keeps every session as a file you own.

  • Chat, tools and background jobs in one window.Ask in plain language; it reads files, runs commands and delegates to helpers.
  • Local first.Nothing is sent anywhere until you pick a provider.
  • Changeable and skippable.Every choice here can be revisited later. Nothing is locked in.

This page is a self-contained demo: it reads and writes no settings and touches nothing on disk.

Step 2 · Security & access

Where it listens, and who can reach it

Loopback by default The web interface binds to 127.0.0.1. Only this machine can open it. Binding 0.0.0.0 is a deliberate choice and brings no TLS, password or origin policy of its own.
Trusted-network model There is no password by default. Anyone who can reach the port has your access. To use it from another device, expose it only inside a trusted private network (VPN, Tailscale, LAN you control), never a bare public port.

Sandbox mode (how much agents may do without asking)

Changeable per session later: the composer's access-mode switch.

Step 4 · Intelligence

Background helpers, on by default

Compaction, the Context Keeper and the Whiteboard are on by default. With free models there is no cost, and each can be switched off with one click.

CompactionOn by default. Shortens a session before it outgrows the model's window.

LLM summary: a model writes the replacement summary. Mechanical fallback (always on, no model call): drops tool-result middles and leaves a stub naming how to recover them; it takes over when the LLM summary is unavailable.

Uses an LLM · route: Kilo free gateway (free) · not your main session model
No model call · the always-on mechanical fallback runs
Context KeeperOn by default. Keeps a short State checkpoint of decisions and open threads, refreshed in the background.

A restarted session still knows where it was. Without it, sessions simply start from their stored history.

Uses an LLM · route: Kilo free gateway (free) · not your main session model
WhiteboardOn by default. A small pinned scratchpad (paths, rules, facts, tasks) re-injected each turn.

Writes happen inside a normal turn: it stores what you or the agent pin. No separate background model call.

Step 6 · Agents

Three helpers, one picker

Agent presets are chosen in the composer. Each has a different job:

Orchestrator Sysadmin Creator each colour marks one agent
  • Primary coding agent Orchestrator The main agent you talk to: planning, writing code, running work. The default seat.
  • Sysadmin Host and ops matters: the system analysis, services and hardware.
  • Knows the whole system Creator Anything about the harness itself: changing, updating, fixing. It knows the whole system and can act on it.
Analyse this system now?Recommended

A read-only scan of hardware, OS and services. It runs in the background while you continue, and it gives your sysadmin knowledge of this machine, so agents answer from facts instead of a default system context.
